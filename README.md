Generated by Phase 1.

## Current stack

- PowerShell
- HTML
- CSS
- JavaScript
- JSON storage

Next phase: storage core.

## Quick Start

```powershell
.\install.ps1
.\build.ps1
.\start.ps1
```

Open **http://localhost:8088** in your browser.

### Features
- Offline-first JSON storage
- PWA (install on mobile)
- Jalali calendar with holidays
- Sales Pipeline (Kanban)
- Knowledge Graph
- SHA-256 Vault security
- AI Insights (offline)
- Full Persian RTL interface
